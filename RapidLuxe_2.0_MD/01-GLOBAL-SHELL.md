# RapidLuxe 2.0 — Global Shell

**Priority:** P0

## Purpose

Specify persistent navigation, footer, theme behavior, account access and global conversion elements.

## Requirements

- Premium wordmark and restrained navigation.
- Journey/search access.
- Wishlist/account access.
- Mobile navigation.
- Persistent but unobtrusive enquiry CTA.
- Existing contact/WhatsApp affordance only where appropriate.
- Footer: brand statement, navigation, legal, newsletter, contact and social links.
- Full dark/light theme correctness.

## Review

**HIGH VALUE.** Fix the shell before page-specific visual work. Existing Navbar, MobileMenu, Footer, SiteChrome and ThemeProvider should be refined rather than replaced.
