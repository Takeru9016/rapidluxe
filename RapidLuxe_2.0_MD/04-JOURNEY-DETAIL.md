# RapidLuxe 2.0 — Journey Detail

**Priority:** P0

## Purpose

Convert a package detail page into a persuasive luxury travel story and high-confidence enquiry entry point.

## Requirements

- Hero: destination, Journey title, duration, price/starting price, Request CTA, wishlist, gallery.
- Journey story: what makes it special, who it suits, Therapycation intent.
- Itinerary: day-by-day, hotels, activities, tours/transfers, flight inclusion.
- Practical information: best time, cancellation, inclusions/exclusions, important notes.
- Social proof using only real server-backed reviews.
- Persistent or strategically repeated Request CTA.

## Review

**REBUILD CONTENT HIERARCHY, NOT THE DOMAIN MODEL.** The current page is feature-rich. 2.0 should reduce cognitive load, strengthen editorial storytelling and avoid instant-checkout expectations.
